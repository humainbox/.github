## Humainbox

We stand between a contact form and the mailbox behind it. Machine-written junk is held
back, the enquiries a person actually wrote go to whoever should answer them, and nothing
is ever deleted.

Started in 2026. One product, no plan for a second.

---

### What is here

One thing, so far.

**[contact-page-study](https://github.com/humainbox/contact-page-study)** — the instrument
behind a measurement of 598 small-business contact pages. Two passes over the same list:
one reads each page the way software reads it, one fetch and no browser; the other opens
the same page in a real browser and reads what a visitor would see. The gap between them
is the study.

It is public because a figure nobody can recheck is a figure nobody should believe, and
almost none of the numbers that study was written against can be rechecked at all. There
is no key, no account and no paid service in it.

The most useful number in the report is the one about our own tool. Of the contact forms
a browser can find, a single static fetch finds **94.3% on WordPress and 21.9% on
Squarespace** — so a fifth of what we looked at was invisible to the method, and which
fifth depends almost entirely on what built the site. That is published alongside every
figure it affects, because a report without error bars is an advertisement.

One of those figures has already moved against us. Squarespace was 14.3% on the first 489
sites; a fifth sample, registered in advance with the rule that it would be published
whichever way it went, took it to 21.9%. Both numbers are printed.

### What is not here

The product. This organisation holds what a reader needs in order to check something we
published — not the application, and not anybody's data. The study's sampling sources are
included so a sample can be redrawn; the list of businesses we measured is not, because
publishing a roster of companies alongside findings about them is a wall of shame, and
that is the opposite of the argument this company makes.

### Elsewhere

**[humainbox.com](https://humainbox.com)**

**[The contact page check](https://humainbox.com/check)** — paste a URL and it tells you
what is publicly true about that contact page: whether a form is found, what is in front
of it, whether an email address is sitting harvestable in the markup, what the DNS says.
One page, no account, no email field, nothing stored. It runs the same static pass this
organisation publishes, and it now says so when it cannot see a page properly.
